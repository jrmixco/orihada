# Orihada

A free, private PDF app for Windows: read, fill, sign and organize PDFs. No account, no ads, no pop-ups.

**Website and download:** https://orihada.com

This repository hosts the website (served by GitHub Pages) and the Windows installers (under [Releases](https://github.com/jrmixco/orihada/releases)). `app/` is the in-browser version of Orihada.
